Regia

A live control room for your Claude Code sessions. Agents, skills, tool calls, context and usage limits on one animated radar, right inside the Code tab.

Install View on GitHub
  • Subagents orbit the core as satellites, beaming while they work.
  • Every tool call is born on the needle and sweeps around in real time.
  • Context fill and your 5-hour limit, always in view.
  • English or Italian, and it honors reduced motion.

The panel is the plugin's real drawing code, running on a simulated session.

Below the radar the panel keeps going: context and usage limits, activity lanes that scroll with time, skills in play, your most-used tools and every file touched.

Install

Requires Claude Code 2.1.293 or later. The graphic panel lives in the desktop app's Code tab; the terminal gets a compact text version.

Install from a terminal session

Type this at the Claude Code prompt, answer y to add the marketplace, then pick the user scope.

/plugin install regia --marketplace purpleheads2026/Mod_claude

Or use the CLI

claude plugin install regia --marketplace purpleheads2026/Mod_claude --scope user

Open it

New sessions load Regia on their own and open the panel at start. In a session that is already open, run /reload-plugins, then /regia.

Pick a language

English by default. For Italian:

echo '{"language":"it"}' | claude plugin configure regia@mod-claude --values-stdin
